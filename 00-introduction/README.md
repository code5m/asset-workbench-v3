# 00 Introduction

This folder contains the human-facing entry layer for Asset Workbench V3.

Purpose:

- explain what the workbench does before showing technical state;
- describe why a project asset space is needed;
- bridge plain language to system terms such as WorkspaceVersion and Raw;
- keep onboarding copy reusable for the frontend welcome and guide pages.

Key principle:

> The user should understand the product before seeing the import console.
