# Asset Workbench V3 Introduction

Asset Workbench turns a changing project folder into a traceable asset space.

It manages more than code:

- source code;
- architecture and product design;
- documents and reports;
- ChatGPT, Codex, CodeBuddy, and human conversations;
- derived outputs such as CodeGraph, semantic indexes, summaries, and tags.

The user flow is:

1. Find project materials.
2. Confirm where they came from.
3. Freeze a project version.
4. Generate searchable assets.

The workbench should not open directly on internal terms. It should first explain
the workflow in ordinary language, then introduce system concepts as needed.
