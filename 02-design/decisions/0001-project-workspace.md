# Decision 0001: Use Project Workspace As Top-Level Model

Status: accepted

## Decision

Asset Workbench V3 uses Project Workspace as the top-level model instead of Code
Workspace.

## Reason

The product needs to manage code, design, documents, conversations, and derived
analysis together. Code-only navigation hides important project assets.

## Consequence

The UI must include an introduction layer, an asset explorer, and a unified file
detail model.
