# Project Asset Space

Asset Workbench V3 uses Project Workspace as the top-level model.

```text
Project Workspace
├── 01-code
├── 02-design
├── 03-docs
├── 04-conversations
└── 05-derived
```

Each asset must be viewable through a common detail model:

- name;
- path;
- type;
- source;
- version;
- updated time;
- summary;
- related assets;
- derived outputs.
